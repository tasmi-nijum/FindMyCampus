## Project Description

FindMyCampus is an augmented reality campus navigation concept designed to help new international students at TH Aschaffenburg find classrooms, the library and other campus facilities.

## How to Open the Website

1. Open the FindMyCampus project folder.
2. Double-click `index.html`.
3. The website will open in a web browser.
4. Use the navigation links to explore the sections.

## Main Features

- AR Navigation Concept
- Classroom Search Concept
- Multilingual Support Concept
- Three-Step User Journey
- Interactive FAQ
- Welcome Audio
- Website Demo Video
